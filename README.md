# 星芽遠征團：放置冒險（v1.0）

原創可愛像素組隊放置 RPG（繁體中文、單一 HTML、PWA）。玩法參考《不休的烏拉拉》（同畫面組隊推圖、職業搭配加成）、《RO仙境傳說：重生》（四職加成、自動探索/離線收益、寵物派遣、副本、流派）、《楓之谷：放置冒險》（章節推圖、星力、潛能、同伴），養成融合 RO（卡片、精煉、Renewal 公式）、楓之谷（單一等級轉職、星力/潛能/套裝）、希望 Online（寵物養成進化、生活技能）。**所有名稱與美術都是原創/影射**，不使用任何原版素材或商標；sprite 全部由程式即時繪製（`image-rendering: pixelated`，無 emoji）。

## 核心系統
- **章節推圖**：20 章 × 10 關（第 11~20 章為「異界深層」）。一般關 3 波，第 10 關是頭目關：限時 60 秒、讀條大招（紫色可打斷、金色不可）、HP<50% 進二階段（換屬性）、剩 20 秒狂暴。失敗會退回上一關掛機，並提示要強化的方向。已過關卡可以回刷。推圖會解鎖夥伴與系統（寵物 1-5、生活 2-1、公會 2-4、副本 2-6、星力 3-1、潛能 4-1）。
- **隊伍同畫面**：最多 5 人站在左側原地攻擊或施法（不會往前衝）。主角由玩家操作，另有 6 位 NPC 夥伴可招募，各自有職業、等級、裝備。加成：四職（每個不同職系 +2.5%，最多 10%，月卡不限職業）、人數（每人經驗 +5%）、鐵三角（坦+補+輸出，ATK/DEF +10%）。
- **仇恨**：傷害、治療、增益都會累積仇恨。坦職有 ×1.6 仇恨、挑釁和戰吼。盜賊有隱匿，服事有寧靜祈禱可降仇恨。近戰仇恨超過 110%、遠程超過 130% 就會 OT。頭目下方顯示目前目標，隊員頭上出現「!」警示。NPC 隊友在仇恨達坦的 90% 時會自動停手。
- **等級與轉職（楓之谷式）**：只有一種等級，Lv10 一轉（六系）、Lv30 二轉（每系兩條，共 12 職）、Lv70 三轉（12 職），滿等 200。
  - 每級給 5 素質點、3 技能點。技能點依轉職階段分池，只能用當前階段的點，可以回點前階技能；上一階段剩下的點不會帶到下一轉。
  - 技能有前置技能、角色等級門檻、主屬性門檻，還有武器/盾/狀態需求（例如音速投擲需要拳刃、阿修羅需要 5 氣彈），以及詠唱、冷卻、後延遲、SP、觸媒等代價。
- **轉生（無限次）**：滿等後花鑽石加金幣（費用遞增）轉生。等級和六維會重置，職業、技能、進度、裝備保留。
  - 每轉初始六維 +3、素質點 +20、技能點 +1、轉生點 +10、HP +1%，經驗需求每轉 +12%。
  - 練回歷史最高等級前經驗 ×2，裝備等級限制看歷史最高等級。
  - 轉生點可以點六維或特化能力（HP、DEF、MDEF、FLEE、暴擊、格擋、減傷等），同一項點越多越貴，收益遞減。
  - 稱號與光環：1 轉白、5 轉藍、10 轉金、20 轉紫、50 轉彩虹。
- **數值（RO Renewal）**：ASPD（上限 193）、變動詠唱與固定詠唱、StatusATK/MATK、硬 DEF 減傷 (4000+DEF)/(4000+DEF×10) 加軟 DEF、HIT/FLEE、暴擊（拳刃 ×2）、屬性與種族相剋。素質提升成本為 (現值−1)/10+2，上限 130，一輪點不滿。後期章節的怪物 HIT/FLEE 門檻較高，要靠 DEX/AGI 和多次轉生。
- **多段技能**：照官方段數分段顯示，例如箭類 = 技能等級段、雷鳴光球 = Lv+2 段、音速投擲 8 段、二連矢 2 段，阿修羅是單段大字。每段各自飄小數字、播打擊特效與音效，打完後在目標上方顯示放大的總傷害。
- **防禦有感**：會飄出「減傷 X%」「格擋」「迴避」字樣，角色面板顯示物理減傷%。防禦技能（自動防禦需盾、光之屏障、神聖庇護、堅忍不拔、神聖盾壁）都有持續時間和冷卻，中間有空窗期，減傷沒有總上限。
- **裝備**：綁定職業與等級，有單雙手、盾、刺影二刀流、拳刃等規則，可以直接精煉身上的裝備。
  - 屬性結構：3 條主屬性（只出六維，其中 1 條固定是職系主屬性）、2 條附加屬性（ATK/MATK、%、暴擊/暴傷、ASPD、詠唱、CD、後延遲、SP 消耗、六維%、HP/SP、DEF/MDEF/FLEE/完全迴避/HIT、屬性/種族/頭目增傷、技能等級或技能傷害）、1 條特殊屬性（花鑽石解鎖或重洗，例如觸發施法、吸血吸魔、暈眩、反傷、無視防禦、穿透 MDEF、CD 歸零、擊殺回 SP，稀有的有全技能 +1、全素質 +5、全傷害%）。
  - 數值範圍依裝備等級提高，品質分五階。
- **強化**：RO 精煉（依武器等級決定每級 ATK、安全值、過精、損壞，+4/+7/+9 發光）、楓之谷星力（★15、降星、爆星）、潛能方塊（稀有到傳奇四階）、套裝、卡片插槽（頭目卡 = 對下一章種族增傷）。
- **寵物（希望式）**：孵蛋、餵食、Lv10/30 進化、參戰攻擊（有屬性），也可以派遣去採集、挖礦、釣魚、狩獵（離線也算）。**生活**：採集、製作藥水、飼料、精煉材料、料理。**副本**：每天 3 次。
- **經濟**：一般商店用金幣（NPC 買賣）；交易所一律用鑽石計價（上架和成交各收 5% 手續費，有搜尋、上架、下架、收購單）；點數商城（鑽石）只賣精煉保護類、改名、變性、結婚、時裝、月卡。商城物品和綁定物品不能交易。
- **其他**：月卡（每天 20,000 金加 30 鑽，經驗和掉落 +20%）、公會（捐獻升級加成）、離線收益（上限 8 小時、效率 50%）、Web Audio 原創音效、PWA（可加到主畫面、離線可玩）、手機版五個主分頁。GM 面板在「更多 → 設定」，密碼 `chou-gm-2026`。

## 程式分層（為多人版預先設計）
`src/` 依序拼接成 `index.html`（`build.sh`）：
| 檔案 | 層 | 說明 |
|---|---|---|
| b.js | DATA | 職業、技能、章節、裝備、卡片、寵物、商城等靜態表（前後端共用） |
| c.js / k.js / l.js | 純函式核心 | 角色數值 calc()、經驗、轉職、轉生、技能點池 |
| d.js | 戰鬥模擬 | `newBattle/stepBattle` 以固定 0.1s tick + 種子 RNG（mulberry32）**可確定性重現**，只輸出事件陣列，不碰 DOM |
| e.js / f.js | 帳號狀態與動作 | 推圖、掉落、精煉/星力/潛能/卡片、寵物、交易所等指令（皆為可序列化 JSON 操作） |
| g.js / h.js / i.js / j.js | 前端 | 像素繪製、事件→特效/飄字/音效、UI、輸入 |

存檔：localStorage key `xyexp_save_v1`（與舊 RO/天堂版互不干擾）。

## 多人架構規劃（下一階段）
- **伺服器**：Zeabur（Node.js），資料庫 PostgreSQL，即時同步用 WebSocket。
- **資料表**：`accounts`（登入、鑽石、月卡）、`heroes`（角色 JSON：等級、轉生、素質、技能、裝備 uid）、`items`（裝備/卡片，有 bound 欄位）、`parties`（隊伍成員、共用推圖進度 ch/st/max）、`market_listings` 與 `market_orders`（交易所，鑽石計價、手續費、托管）、`guilds`。
- **共推進度**：隊伍持有一份 `prog`。伺服器每隊跑一個權威 `stepBattle`（直接沿用 d.js），種子由伺服器產生，前端只收事件串播放動畫，避免作弊。經驗和掉落各自入帳。
- **離線隊友**：離線成員改由 AI 代打（沿用 `pickSkill` 與 `holdOT`），只要一人在線，全隊就能推進。也可以用「代設定」幫隊友調整技能優先順序。
- **交易所上線**：把目前 NPC 模擬的 `exTick` 換成真實撮合。鑽石先凍結托管，成交時扣手續費。
- **排行榜/炫耀**：轉生次數與稱號存在 `heroes.rb`，在隊伍、排行榜、交易所賣家欄都會顯示。

## 測試與平衡
- `test.py`：Playwright 用 iPhone 13 觸控模擬跑完整流程，截圖放在 `screens/`。
- `sim_report.js`：各章頭目 × 培養程度勝率、深層章節所需轉生次數、HIT/FLEE 門檻 → `sim_boss_result.txt`。
- `sim_class.js`：各職業 DPS、生存、混合配點，以及有坦/無坦、有補/無補、防禦高低、打斷開關的隊伍對照 → `sim_class_result.txt`。
- `calib.js` 和 `calib_class.js`：自動校正頭目血量係數（CHB）和職業傷害係數（JDM）。
