# 王權紀元：放置征戰
原創中世紀奇幻放置 RPG（致敬經典 MMORPG 玩法；名稱、美術、音效皆原創）。單檔 index.html + PWA，存檔 localStorage key `ql-idle-v1`。
- 職業：王族/騎士/妖精/法師/黑妖，創角 75 點配點，Lv51 起每級 +1 素質點
- 數值：力量/敏捷/體質/精神/智力/魅力 → AC(越低越硬)、命中、額外傷害、SP、MR、HP/MP 回復；死亡損失 5% 經驗（經驗回復卷軸取回）
- 衝裝：一般/祝福(+1~3)/詛咒卷軸，武器安定 +6、防具 +4、妖精裝 +6，超過安定值可能蒸發；保護卷軸；可直接衝身上裝備；+5 起發光
- 變身卷軸/變身卡、魔法娃娃、魔法書學魔法、妖精屬性、隊伍 NPC 倍率、血盟、攻城戰報、7 張地圖與頭目重生
- 點數商城（鑽石）、月卡、GM（密碼 chou-gm-2026）、離線收益（8h、30%）、翅膀（寶石合成）
